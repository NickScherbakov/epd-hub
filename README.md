# EPD-Hub 🚀

**Интеллектуальная платформа мониторинга электронных перевозочных документов (ЭПД)**

> Real-time обновления нормативной базы • Автоматизированная генерация контента • Персонализированные уведомления

---

## 📋 Описание проекта

EPD-Hub — это комплексная платформа, которая решает проблему постоянного отслеживания изменений в нормативной базе по электронным перевозочным документам (ЭПД), введенным Федеральным законом от 07.06.2025 № 140-ФЗ.

**Ключевые возможности:**

- 🤖 **Автоматический мониторинг** — 24/7 crawler'ы отслеживают изменения на официальных источниках (ФНС, Минтранс, ГОСТ и т.д.)
- 🧠 **Интеллектуальный анализ** — LLM анализирует изменения и определяет, какие документы и процессы они затрагивают
- 📱 **Персонализированные уведомления** — настраиваемые alerts в Telegram, Email и через веб-панель
- 📚 **Автоматическая генерация контента** — курсы, шаблоны и чек-листы обновляются в реальном времени
- 🔗 **API для интеграций** — подключите EPD-Hub к своим системам

## 🚀 Быстрый старт

### Требования
- Python 3.11+
- PostgreSQL 14+
- Docker & Docker Compose (опционально)

### Установка (локальная разработка)

\`\`\`bash
# Клонируем репозиторий
git clone https://github.com/NickScherbakov/epd-hub.git
cd epd-hub

# Создаем виртуальное окружение
python -m venv venv
source venv/bin/activate  # на Windows: venv\Scripts\activate

# Устанавливаем зависимости
pip install -r requirements.txt

# Копируем .env.example в .env и заполняем переменные
cp backend/.env.example backend/.env

# Запускаем сервер разработки
cd backend
uvicorn app.main:app --reload
\`\`\`

Сервер будет доступен по адресу: http://localhost:8000

**API документация (Swagger):** http://localhost:8000/docs

### Docker запуск

\`\`\`bash
docker-compose up -d
\`\`\`
